# Focus Flow

A simple dynamic task manager built with Vanilla JavaScript, HTML, and CSS.

## Features

- Add tasks from a modal form
- Validate task title (required, minimum 3 characters)
- Mark tasks as completed
- Delete tasks
- Filter tasks by `All`, `Active`, and `Completed`
- Empty state when there are no visible tasks
- Responsive layout for mobile and desktop
- Human-friendly created timestamp

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
